# 🎬 Movie Search App

A simple web app to search movies using the OMDb API. Built with **HTML, CSS, JavaScript** on the frontend and **Node.js + Express** on the backend.

---

## 🚀 Features
- Search movies by title
- Display poster, year, genre, actors, and plot
- Interactive movie cards (click to expand details)
- Responsive design for desktop and mobile
- Error handling for invalid searches
- Vibrant UI with gradient background and styled movie cards

## 🔑 Setup
1. Navigate to backend and install dependencies:
   ```bash
   cd backend
   npm install

Add your OMDb API key to .env:
API_KEY=your_api_key_here

Start the server: 
npm start

Open http://localhost:5000 in your browser.
